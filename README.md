# MNIST Digit Classification (CNN + RNN)

This project implements a hybrid deep learning model combining Convolutional Neural Networks (CNN) and Recurrent Neural Networks (RNN) for handwritten digit classification using the MNIST dataset.

## Features
- Uses CNN for feature extraction from images
- Uses RNN (LSTM/GRU) for sequence-based learning
- Trained and evaluated on MNIST dataset
- Achieves 95%+ accuracy in digit classification

## Tech Stack
- Python
- TensorFlow / Keras
- NumPy, Matplotlib

## Dataset
- MNIST handwritten digit dataset
